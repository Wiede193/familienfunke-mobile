# Lizenz und Quelle der PLZ-Mittelpunkte

Quelle: **Wissenschaftszentrum Berlin für Sozialforschung (WZB)**, Markus Konrad, Januar 2019.

Original: https://github.com/WZBSocialScienceCenter/plz_geocoord

Quelldatei: `plz_geocoord.csv`, Lizenz **Apache License 2.0**.

Die ursprünglichen PLZ-Gebietsmittelpunkte wurden aus einem Geocoding-Datensatz vom 7. Januar 2019 gewonnen. In Familienfunke haben wir die geografischen Mittelpunkt-Koordinaten auf 0,01 Grad gerundet und als zweistellige Ganzzahlen im lokalen Javascript-Datensatz `data/plzCentersGermany.js` gespeichert. Das ist eine **bearbeitete Kopie**, nicht die unveränderte Quelldatei. Die 2019er Zuordnung kann veraltet oder ungenau sein; sie ist nicht geeignet für genaue Entfernungen, Navigation oder Standorte privater Haushalte.

Für die Nähe-Suche ist die Eingabe einer deutschen PLZ freiwillig. Sie wird im App-Speicher nur vorübergehend während der Eingabe gehalten; die App speichert auf dem Server ausschließlich einen gerundeten Gebietsmittelpunkt, wenn ein erwachsenengeprüfter Nutzer die Suche ausdrücklich aktiviert.
